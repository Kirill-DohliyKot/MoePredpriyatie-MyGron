## 🎯 Описание проекта

**Industry Future** - это мобильное приложение для соединения промышленных предприятий Москвы с талантливыми школьниками и студентами через создание тематических сообществ, решение реальных кейсов и формирование цифрового портфолио.

### Решаемые проблемы:
- **Для предприятий**: Нехватка молодых специалистов, формальные программы стажировок
- **Для молодёжи**: Отсутствие "точек входа" в промышленность, невозможность получить практический опыт

## 🚀 Функциональность

### Для участников:
- ✅ **Лента активностей** - персонализированные новости и мероприятия
- ✅ **Сообщества** - поиск и присоединение к тематическим клубам
- ✅ **Проекты** - участие в реальных производственных кейсах
- ✅ **Профиль** - цифровое портфолио с навыками и достижениями
- ✅ **Геймификация** - система уровней, бейджей и рейтингов

### Для предприятий:
- ✅ **Конструктор сообществ** - создание тематических клубов
- ✅ **Управление контентом** - публикация мероприятий и материалов
- ✅ **Система проектов** - размещение реальных производственных задач
- ✅ **Поиск талантов** - аналитика участников по навыкам и активности

## 📱 Установка и запуск

### Предварительные требования:
- Node.js 16+
- npm или yarn
- Expo CLI
- Android Studio / Xcode (для эмуляторов)

### Установка:

1. **Клонирование репозитория:**
```bash
git clone <repository-url>
cd industry-future-app
```

2. **Установка зависимостей:**
```bash
npm install
```

3. **Запуск приложения:**
```bash
# Запуск в режиме разработки
npm start

# Запуск на Android
npm run android

# Запуск на iOS
npm run ios

# Запуск в браузере
npm run web
```

## 🧩 Основные компоненты

### Модели данных:

#### Community (Сообщество)
```javascript
{
  id: string,
  name: string,
  description: string,
  logo: string,
  directions: string[],
  members: string[],
  projects: Project[]
}
```

#### Project (Проект)
```javascript
{
  id: string,
  title: string,
  description: string,
  requiredSkills: string[],
  difficulty: 'beginner' | 'intermediate' | 'advanced',
  deadline: Date,
  participants: string[]
}
```

#### User (Пользователь)
```javascript
{
  id: string,
  name: string,
  email: string,
  skills: string[],
  completedProjects: Project[],
  badges: Badge[],
  rating: number,
  level: number
}
```

## 🔌 API и сервисы

### Firebase:
- **Firestore** - хранение данных
- **Authentication** - управление пользователями

### REST API:
- `apiService.getCommunities()` - получение списка сообществ
- `apiService.getProjects()` - получение проектов
- `apiService.joinProject()` - присоединение к проекту
- `apiService.getUserProfile()` - получение профиля пользователя

### Gamification Service:
- Расчет уровней и прогресса
- Управление бейджами и достижениями
- Система начисления очков

## 🔧 Разработка

### Добавление нового экрана:

1. Создайте файл в папке `screens/`
2. Импортируйте в `App.js`
3. Добавьте в навигацию

### Работа с данными:

```javascript
import { apiService } from './services/api';

// Получение данных
const communities = await apiService.getCommunities();

// Обновление данных
await apiService.updateUserSkills(userId, skills);
```
